# __init__.py

## __init__.pyの主な利用用途
- 公開APIの整理
  - 外部からインポートしやすくなる
  - サブモジュールなどが深い階層にある場合は設定したほうが楽
- パッケージ全体の初期化処理が必要な場合
  - パッケージが読み込まれたときに一度だけ実行したい処理がある場合。
  - 例：ログ設定、環境変数の読みこみ
- 公開範囲の指定
  - __all__を定義することで、`from package import *`の場合の挙動を制御できる。

## 記載イメージ
```py
# サブモジュールから主要な関数をインポートしておく
from .solver import solve
from .tools import visualize

# バージョン情報の定義
__version__ = "1.0.0"

# 「*」でインポートされたときに許可するものを指定
__all__ = ["solve", "visualize"]
```


具体的にはsrcフォルダ配下に配置することで、notebookからの呼び出しが楽になる
